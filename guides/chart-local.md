## 그래프 만들기 — 표 → 여러 그래프 후보 → 고칠 수 있는 문서로
표를 붙여 넣으면 어울리는 그래프를 여러 개 한꺼번에 그려 보여 주고, 고른 그래프를 엑셀·파워포인트·워드·한글 문서에 **값을 고칠 수 있는 차트**로 담아 줍니다.

> 처음 들어오면 **따라 하기**가 저절로 뜹니다(다시 보려면 머리줄 **따라 하기** — 약 3분 — 샘플 표 → 후보 → 편집 → 문서 내보내기): 연습 자료로 화면을 직접 눌러 보며 배우고, 연습으로 만든 기록은 끝에서 지울 수 있습니다. **?** 창의 **영상으로 보기**로 먼저 볼 수도 있습니다.

### 쓰는 법
1. **데이터 넣기** — 엑셀에서 표(머리글 포함)를 복사해 붙여 넣기(Ctrl+V, 바로 읽힘) 또는 CSV·XLSX 올리기(시트 선택). 처음이면 **샘플**(연도별 예산·실험 측정값·부서별 비율·주가·역량 평가·월별 손익·채용 단계·목표 대비 실적·기준금리·시도별 지표·월별 운영 지표·월별 강수량·주가 일봉 160일(가상 데이터))
2. 읽힌 표 확인 — 열 머리글에서 **이름·타입(숫자/날짜·기간/범주)·단위**를 고치거나 열을 뺄 수 있음. 연도가 가로로 놓인 표는 자동으로 행·열을 바꿈(**행·열 바꾸기** 버튼도 있음)
3. **그래프 후보** — 데이터 모양에 맞는 6~12개가 카드로 바로 나옴(규칙 추천). 카드마다 '왜 이 그래프인지' 한 줄, 잠시 뒤 로컬 LLM 이 제목·설명을 붙임
   - 이어서 **AI 추천 순위**: 로컬 LLM 이 이 표에 더 알맞은 순서로 카드를 다시 늘어놓음(카드에 'AI 추천 순위 N' 배지·'AI' 이유 한 줄). 위의 **규칙 순서로** 를 누르면 원래 순서로, **AI 추천 순위** 로 다시
   - 다른 종류가 더 알맞다고 보면 **AI 제안** 카드(최대 3개)가 맨 뒤에 붙음 — 서버가 열·조건을 검사하고 실제로 그려 본 것만. 다른 카드처럼 편집·문서에 담기 가능
   - LLM 이 꺼져 있거나 느리면 규칙 순서 그대로 쓰고 작은 안내만 나옴. 같은 표를 이력에서 다시 열면 저장된 AI 순위가 그대로 나옴(다시 받으려면 **AI 순위 다시 받기**, 10분에 10번까지)
4. 카드를 누르면 **편집** — 제목·부제·종류·x/값 열·그룹·축 이름·범례 위치·값 라벨·정렬·계열 켜고 끄기·색. 바꾸면 바로 반영. **복제해서 변형 만들기**, SVG/PNG 저장
5. 마음에 드는 카드의 **문서에 담기**를 체크(여러 개, 체크한 순서대로 들어감) → 문서 제목 → **엑셀 / 파워포인트 / 워드 / 한글** 중 하나
6. 결과에 그림마다 **어떤 방식으로 들어갔는지**(네이티브 차트 / 색 칠한 표 / 그림+표)와 파일 구조 검사 결과가 나옴 → 내려받기

### 받은 파일에서 고치기
- **엑셀**: '데이터' 시트 값을 고치면 그림 시트의 표(수식)와 차트가 함께 바뀜
- **파워포인트·워드**: 차트 오른쪽 클릭 → **데이터 편집**
- **한글**: 차트 개체를 두 번 눌러 차트 데이터 편집. 상자그림·히트맵·이중축과 새 종류(방사형 빼고)는 그림 + 표로 들어감

### 팁
- 단위가 다른 두 값(예: 예산 억원·인원 명)은 **이중축**(왼쪽 축 막대 + 오른쪽 축 꺾은선) 후보가 나옵니다. 범례에 '(오른쪽 축)', 축 제목은 계열 색. 두 축 눈금은 서로 독립이라 막대·선 높이로 추세를 비교하면 오해할 수 있습니다 — 그럴 땐 **위·아래 두 그래프**나 **지수(첫 값=100)** 후보를 쓰세요
- 이중축 편집: 오른쪽 축 열·축 이름, 모양(막대+선 / 선+선), 축 시작(둘 다 0부터 / 오른쪽 축은 데이터 범위). 음수가 있으면 두 축의 0선이 맞춰집니다
- 이중축은 엑셀·파워포인트·워드에서 차트(보조 세로 축)로 들어가고, **한글(HWPX)에서는 그림 + 표**로 들어갑니다(한글 차트 생성기가 보조 축을 지원하지 않음)
- 원그래프는 항목 2~6개·모두 양수일 때만 후보로 나옵니다

### 주가 차트 — 이동평균·볼린저·MACD·RSI·매물대
시가·고가·저가·종가(+거래량) 표면 **캔들 + 이동평균**, **캔들 + 볼린저**, **캔들 + 거래량·MACD·RSI**, **캔들 + 매물대**, **OHLC 막대** 후보가 함께 나옵니다(기간이 지표 창보다 길 때만). 편집에서 직접 켜고 끌 수 있습니다.
- **이동평균** 5·20·60·120일 — 종가 평균. 기간보다 긴 창은 고를 수 없고, 앞쪽(창−1)은 비어 있습니다
- **볼린저 밴드** — 20일 평균 ± 2 × 표준편차(모집단 표준편차, 흔한 차트 프로그램과 같음). 기간·배수를 바꿀 수 있음
- **아래 칸** — 거래량(막대 색 = 그날 상승·하락), MACD(12·26·9, 기간 34개 이상), RSI(14, 와일더 방식, 70 과열·30 침체 점선, 기간 15개 이상). 날짜 축을 함께 쓰고 가격 칸이 가장 큼
- **매물대** — 오른쪽에 가격대별 거래량. 하루 거래량을 그날 저가~고가에 고르게 나눠 더함. 주황 = 거래가 가장 많은 가격(POC), 진한 회색 = 거래의 70% 가 모인 범위
- **상승·하락 색** — 한국식(상승 빨강·하락 파랑, 기본) / 국제식(상승 초록·하락 빨강)
- 문서: 엑셀·파워포인트·워드에 **차트**로(가격 + 이동평균·볼린저 선, 거래량·MACD·RSI·매물대는 각각 차트). 볼린저의 색 띠는 그림에서만(문서는 선 3개). 한글은 그림 + 표
- **엑셀에서 가격을 고치면 지표가 다시 계산됨** — 그림 시트의 이동평균·볼린저·MACD·RSI·매물대 거래량이 엑셀 수식. 파워포인트·워드의 '데이터 편집'에는 계산된 값이 들어 있어 가격을 고쳐도 지표는 그대로
- 워드 파일을 LibreOffice 로 열면 가격 차트(캔들 + 선)가 어긋나 보일 수 있습니다 — LibreOffice 에서는 파워포인트·엑셀 파일로 보세요

### 막대 위에 추세선
세로·가로·묶은·누적 막대 편집에서 **추세선**: 추세선 없음 / 직선(최소제곱) / 이동평균 n. 계열마다 같은 색 점선(누적 막대는 합계의 추세 하나). x 가 월·연도 같은 기간이면 '막대 + 직선 추세' 후보도 나옵니다.
엑셀·파워포인트·워드에는 프로그램의 추세선으로 들어가 값을 고치면 따라 바뀝니다(누적 막대는 '합계 추세' 선). 한글은 그림 + 표.

### 색 프로필 — 색 묶음 한 번에 바꾸기
- 후보 갤러리 위 **색 프로필**에서 고르면 모든 후보와 내보내는 문서(엑셀·파워포인트·워드·한글 차트)가 그 색으로 바뀝니다: 기본 · 파스텔 · 선명(비비드) · 고대비 · 색각이상 배려(Okabe–Ito) · 흑백 인쇄 · 따뜻한 색 · 차가운 색 · 단색 계열 · 보고서용
- **흑백 인쇄** — 회색 단계에 막대·원 조각은 빗금·점·격자 같은 **무늬**, 꺾은선은 점선·파선 같은 **선 모양**을 넣어 흑백 프린터로 뽑아도 계열이 구분됩니다(문서 차트도 같음, 한글 차트는 무늬 없이 회색 단계만)
- **단색 계열** — 한 색의 진함→옅음. 누적 막대나 1분기→4분기처럼 순서가 있는 계열에 알맞음. 히트맵·트리맵은 어느 프로필이든 그 프로필 주 색의 명도 단계
- 그래프 하나만 다르게: 편집 칸 **색 프로필 (이 그래프만)**. 계열마다 직접 고른 색이 프로필보다 먼저이고, **색 프로필 색으로** 를 누르면 되돌아감
- **내 색 프로필** — '지금 색 고쳐서 내 색 프로필로 저장' 에서 색을 바꿔 저장. 고른 프로필과 내 색 프로필은 **이 브라우저에만** 기억됩니다(다른 PC·브라우저에서는 다시 골라야 함)
- **원본 그림 색** — 디지타이저에서 내보낸 엑셀을 올리면 원래 그림의 계열 색으로 그리는 프로필이 생깁니다
- 주가 차트의 상승·하락 색과 폭포의 증가·감소 색은 관례대로 두고, 이동평균·지표 선과 합계 막대만 프로필 색을 씁니다

### 표 읽기 팁
- `1월…12월`, `1분기`, `Q1`, `1주차` 같은 열은 숫자가 아니라 **기간**으로 읽어 x 축이 됩니다(디지타이저에서 받은 CSV·엑셀도). 값이 모두 빈 열은 빼고 알려 줌

### 그래프 종류 (34가지)
막대·꺾은선·영역·원·도넛·산점도·히스토그램·상자그림·히트맵·이중축 등 기존 종류에 더해 아래 15가지가 있습니다. 표 모양이 맞으면 후보로 나오고, 편집의 **그래프 종류**에서 직접 바꿀 수도 있습니다.

| 종류 | 이럴 때 | 편집에서 고르는 것 | 엑셀·파워포인트·워드 | 한글 |
|---|---|---|---|---|
| 방사형 | 역량·평가 점수처럼 항목 3~12개를 여러 사람·대상으로 비교 | 값 열(1~5개) | 차트 | 차트 |
| 스파크라인 | 단위가 다른 지표 여러 개의 추세를 한눈에 | 값 열(여러 개) | 엑셀은 **셀 안 스파크라인**, 파워포인트·워드는 작은 꺾은선 차트 | 그림+표 |
| 캔들스틱 | 날짜 + 시가·고가·저가·종가 표 (오름 빨강·내림 파랑) | 값 열 4개를 그 순서로, **거래량 열**(선택), 이동평균·볼린저·아래 칸·매물대·색 관례 | 주식형 차트 + 지표 차트 | 그림+표 |
| OHLC 막대 | 캔들 대신 세로선(고가~저가) + 왼쪽 눈금 시가·오른쪽 눈금 종가 | 캔들과 같음 | 주식형 차트(종가 표식 색) + 지표 차트 | 그림+표 |
| 폭포 | 월별 손익처럼 늘고 줄어든 몫이 쌓여 결과에 이르는 과정 | **합계 막대로 볼 항목**(기초·기말 잔액 등), 끝 합계 막대 | 누적 막대(투명 '기준' 계열) | 그림+표 |
| 깔때기 | 지원→서류→면접처럼 단계마다 줄어드는 수 (전환율 표시) | 값 열 | 가운데 맞춘 가로 막대 | 그림+표 |
| 거품 | 숫자 세 개(x·y·크기)를 한 번에 | x·y 열, **원 크기 열**, **점 이름 열** | 거품형 차트 | 그림+표 |
| 계단선 | 금리·요금처럼 값이 유지되다 바뀌는 흐름 | 값 열 | 그림+표 | 그림+표 |
| 막대사탕 | 항목이 많을 때 막대 대신 점+줄기 | 값 열 | 차트 | 그림+표 |
| 덤벨 | 두 시점·목표/실적 두 값의 차이 | 값 열 2개 | 차트 | 그림+표 |
| 트리맵 | 항목이 많아 원그래프가 어려운 구성비 | 값 열 | 그림+표 | 그림+표 |
| 목표 대비(불릿) | 실적 막대 + 목표 눈금, 달성률(%) | **목표 열** | 차트 | 그림+표 |
| 방사 면적(로즈) | 1~12월처럼 한 바퀴 도는 범주 | 값 열 | 그림+표 | 그림+표 |
| 누적 막대 + 꺾은선 | 비용 구성(누적)과 예산·목표(선)를 같은 축에서 | **꺾은선 열** | 차트 | 그림+표 |
| 반원 도넛 | 좁은 자리에 넣는 구성비 | 값 열 | 차트(아래 반은 투명 조각) | 그림+표 |

- '그림+표'는 그 프로그램 차트에 같은 형식이 없어서입니다. 그림 아래 데이터 표를 고친 뒤 이 화면에서 그림을 다시 만드세요. 결과 표에 그림마다 어떻게 들어갔는지 그대로 나옵니다
- 폭포·캔들의 색은 계열 대신 뜻(증가·감소·합계 / 상승·하락)으로 고릅니다
- 폭포 누적이 0 아래로 내려가면 엑셀·파워포인트에서는 맞게 보이지만 LibreOffice 에서는 막대 위치가 어긋날 수 있습니다
- 같은 항목이 여러 행이면 합계로 묶습니다(편집에서 평균으로 바꿀 수 있음). 긴 형식(연도·부서·값)은 자동으로 부서별 계열로 나눕니다
- 제목·설명 제안과 AI 이유는 숫자를 새로 만들지 않습니다. 표에 없는 숫자가 들어간 문장은 버리고 규칙 기반 제목을 씁니다
- AI 는 순서를 바꾸고 제안만 합니다. 그래프의 값은 늘 표에서 읽고, 원그래프 7개 이상·음수 누적처럼 맞지 않는 그래프는 AI 가 제안해도 걸러집니다
- **이력** 탭에서 지난 표를 다시 열고, 내보낸 파일을 다시 받을 수 있습니다(서버의 도구 데이터 폴더)
- 이력은 사용자별로 따로 저장됩니다(포털 계정 기준). 서버 주인은 예전 기록 포함
