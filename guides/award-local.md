## 상장 생성기 — 상장·표창장·감사장 만들기
디자인을 고르고 상훈·수상자·기관을 넣으면 A4 상장을 미리 보고 PDF·PNG(300dpi)로 받습니다. 여러 명도 한 번에.

### 쓰는 법
1. **디자인** 7종(전통 금색·청색 공문형·모던·한지·리본 메달·흰 바탕 금테·모서리 금띠) 중 견본 그림을 보고 고르고, 용지(A4 세로/가로)와 **번호**(이력 기준 다음 번호가 자동으로 채워짐) 확인
2. **상훈 종류**(상장·표창장·감사장·공로상·우수상, 또는 직접 입력)와 **상훈명**(부제, 예: 2026년도 연구성과 우수상)
3. **수상자** 성명·소속·직위, **수상 문구**는 기본 문구 5~6개 중 고르거나 직접 고쳐 쓰기 → **✨ 상장 문체로 다듬기**(로컬 LLM)
4. **수여** 일자(기본 오늘)·기관명·직함·성명, **직인**(기관명으로 자동 생성 — 사각/원형, 또는 이미지 올리기), **기관 마크**(선택, 직접 올린 파일)
5. 오른쪽 미리보기 확인 후 **PDF 내려받기 / PNG (300dpi) / 인쇄**
6. 여러 명: **일괄 발급** 탭에 엑셀에서 복사한 표(이름·소속·직위·[문구]) 붙여넣기 또는 .csv/.xlsx → **일괄 발급**(PDF 한 파일 또는 사람별 ZIP)

### 팁
- **모서리 금띠**는 '금띠 모서리'에서 네 모서리 / 왼쪽 위·오른쪽 아래 두 모서리를 고를 수 있습니다
- 내려받기·인쇄를 해야 **발급 이력**에 남고 번호가 다음으로 넘어갑니다. 미리보기는 기록되지 않습니다
- 일괄 발급은 '번호' 칸부터 1씩 올립니다(2026-009 → 2026-010…). 목록에 문구 칸이 있으면 그 사람만 그 문구
- **발급 이력** 탭에서 지난 발급본 PDF를 다시 받을 수 있습니다
- 인쇄할 때는 배율 **실제 크기(100%)**. PDF는 300dpi 이미지라 글자 선택은 안 됩니다
- 직인 글자는 비우면 '기관명+장인'(예: ○○연구원장인)으로 자동. 실제 직인 날인이 필요한 문서는 기관 절차를 따르세요
- 입력값은 이 브라우저에 기억됩니다(로고·직인 파일은 서버의 도구 데이터 폴더에 보관)
