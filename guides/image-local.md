## 그림 생성 — 말로 그리고, 말로 고치기
글로 설명하면 그림을 그리고(Qwen-Image-2512), 있는 그림을 말로 고칩니다(Qwen-Image-Edit-2509). 모두 이 서버 GPU 에서 돌고 밖으로 나가는 것은 없습니다.

### 그리기
1. 무엇을 그릴지 한국어로 편하게 씁니다. 그림 안에 넣을 글자는 **따옴표**로 감싸 주세요 — 예) 안전 캠페인 포스터, 제목 "안전이 먼저입니다"
2. **스타일**(그대로·사진·일러스트·3D·애니메·수채화·포스터/인포그래픽·로고·제품 사진)과 **비율**(1:1, 16:9, 9:16, 4:3 …)을 고릅니다
3. 장수(1~4)·품질(빠르게 20단계 / 보통 30 / 고품질 50)·번호(#, 같은 번호면 같은 그림)를 정하고 **그리기**
- **프롬프트 다듬기(LLM)** 가 켜져 있으면 짧은 요청을 그림 모델이 잘 알아듣는 자세한 영어 설명으로 바꿔서 그립니다(실제로 보낸 문장이 화면에 나옴). 원하는 그대로 그리려면 끄세요
- 속도: 보통 품질 한 장 약 25초. 처음 한 번은 모델을 GPU 에 올리느라 30초~1분 더 걸리고, 10분 동안 안 쓰면 다른 도구를 위해 GPU 를 비웁니다
- 다른 도구가 GPU 를 많이 쓰고 있으면 자동으로 느린 방식(장당 약 1분)으로 돌아갑니다

### 고치기
1. **고치기** 탭에 그림을 끌어다 놓거나, 갤러리·결과에서 **✏️ 이걸로 고치기**
2. 어떻게 고칠지 씁니다 — "배경을 겨울 숲으로", "고양이를 지워 줘", "수채화 느낌으로", 간판 글자 바꾸기 등. 그림을 2~3장 넣으면 "1번 사람에게 2번 옷을 입혀 줘" 처럼 합칠 수 있습니다
3. **고치기** — 한 장 약 25초(처음엔 모델 준비 1분 더). 결과는 약 100만 화소(예: 1376×768)로 나옵니다

### 갤러리
- 끝까지 그려진 것만 올라갑니다. 누르면 크게 보기 → ⬇ 받기 · ✏️ 고치기 · ↻ 같은 설정으로 다시 · 🗑 지우기
- 지운 것은 데이터 폴더의 `.trash/` 로 옮겨 둡니다(되살리려면 폴더를 다시 꺼내면 됨)

### 알아둘 것
- 한글 글자는 두세 글자 간판·제목 정도는 잘 쓰지만, 긴 문구는 비슷한 다른 글자로 나오기 쉽습니다(예: 안전이 먼저입니다 → 안궁이 대처입니다). 정확한 문구가 필요하면 글자 없이 그린 뒤 PPT·한글에서 얹으세요. 고치기에서 한글을 바꾸면 비슷한 다른 글자로 나오기도 합니다(예: 라멘 → 라번) — 여러 장 뽑아 고르세요
- 그림 모델과 고치기 모델은 한 번에 하나만 GPU 에 올라갑니다. 번갈아 쓰면 바꿀 때마다 30초~1분 더 걸립니다
- 실존 인물·유명인 그림, 동의 없는 실제 사람 사진 편집, 사칭, 선정적인 그림은 만들지 마세요(선정적인 결과는 서버가 항상 걸러 내도록 설정)
