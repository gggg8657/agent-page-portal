## 에이전트 포털
내부망 로컬 LLM 도구들을 한 곳에서 찾고 여는 곳입니다. 외부로 나가는 데이터는 없습니다.

### 쓰는 법
1. **검색창**에 하고 싶은 일을 쓰고 Enter — 예: 회의록, HWP, 그림
2. 카테고리 칩(문서·회의·그림·음성·데이터·재미)으로 좁히기
3. 카드의 **열기**로 도구 진입. 꺼져 있으면 **시작** 또는 **실행 방법 보기**
4. ❤ 좋아요, ☆ 즐겨찾기 — 왼쪽 메뉴 '즐겨찾기'·'최근 사용'에 모입니다

### 팁
- 각 도구 안에서 오른쪽 위 **?** 를 누르면 그 도구의 사용법이 다시 뜹니다
- 도구 결과는 각 도구 폴더의 `_workspace/` 에 남습니다
- 화면 아래를 돌아다니는 **파동이 펫**: 누르면 반응, 끌어서 옮기기, 더블클릭하면 말 걸기. 마우스를 올리면 나오는 **⋯** 메뉴에서 2D/3D·소리·혼잣말·이름을 바꾸고 **펫 끄기**를 할 수 있습니다(왼쪽 아래 동그라미로 다시 부르기)
