## 에이전트 포털
내부망 로컬 LLM 도구들을 한 곳에서 찾고 여는 곳입니다. 외부로 나가는 데이터는 없습니다.

### 쓰는 법
1. **검색창**에 하고 싶은 일을 쓰고 Enter — 예: 회의록, HWP, 그림
2. 카테고리 칩(문서·회의·그림·음성·데이터·재미)으로 좁히기
3. 카드의 **열기**로 도구 진입. 꺼져 있으면 **시작** 또는 **실행 방법 보기**
4. ❤ 좋아요, ☆ 즐겨찾기 — 왼쪽 메뉴 '즐겨찾기'·'최근 사용'에 모입니다

### 팁
- 각 도구 안에서 오른쪽 위 **?** 를 누르면 그 도구의 사용법이 다시 뜹니다
- 처음 오면 **가입**(아이디·이름·부서·PIN 숫자 4~8자리) 후 로그인합니다. PIN 은 서버에 해시로만 저장되어 아무도 볼 수 없고, 잊으면 관리자에게 초기화를 부탁하세요. 오른쪽 위 이름 옆 **계정 설정**(이름·부서·PIN 바꾸기)·**로그아웃**
- **부서**는 목록에서 고르고, 그 부서 **부서장이 승인**하면 반영됩니다(부서장이 없으면 관리자). 목록에 없는 부서는 관리자에게 요청하세요. **부서장 권한**은 계정 설정에서 관리자에게 요청합니다
- 부서장은 자기 부서 가입 요청을 승인·거절하고 구성원 목록·포털 사용 횟수를 봅니다. 승인할 요청이 있으면 위쪽에 **요청 N** 이 뜹니다
- 도구 기록은 **계정별로 따로** 저장됩니다. 다른 사람에게는 안 보이고, 서버 주인은 예전 기록까지 함께 봅니다
- **작업 끝 알림**: 1분 넘게 걸리는 작업(회의록·그림·영상 등)을 걸어 두고 다른 화면에 가 있어도, 끝나면 포털 화면 왼쪽 아래(또는 브라우저 알림)로 "○○ 작업 끝 (N분)" 이 뜹니다. 끄기: **?** 창 아래 '작업 끝 알림' 체크 해제
- 홈 아래 **GPU 사용 현황**에서 GPU 마다 얼마나 차 있고 어느 도구가 쓰는지 볼 수 있습니다. 꽉 찬 GPU 가 있으면 큰 작업은 잠시 뒤에
- 기록은 매일 새벽 3시에 자동 백업됩니다(7일치 보관)
- 화면 아래를 돌아다니는 **파동이 펫**: 누르면 반응, 끌어서 옮기기, 더블클릭하면 말 걸기. 마우스를 올리면 나오는 **⋯** 메뉴에서 2D/3D·소리·혼잣말·이름을 바꾸고 **펫 끄기**를 할 수 있습니다(왼쪽 아래 동그라미로 다시 부르기)
