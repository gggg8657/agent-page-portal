## SQL — 자연어로 데이터 질의
"부서별 예산 합계 큰 순서로"처럼 물으면 SQL을 만들어 실행하고 표와 차트로 보여줍니다. 읽기 전용입니다.

### 쓰는 법
1. 왼쪽 **스키마**에서 테이블·컬럼에 한글 설명을 적어 두면 정확도가 크게 오릅니다(저장)
2. 질문 입력 → **실행** → 표(열 클릭 정렬)·차트·설명
3. **SQL 보기/수정 후 재실행**으로 손보기, **CSV** 내려받기
4. 이어서 질문하면 앞 결과를 기억합니다

### 알아둘 것
- SELECT만 허용, 500행 제한, 10초 제한. 데이터는 바뀌지 않습니다
- 샘플 DB(연구과제·집행·인력·장비·논문)가 들어 있고, `DB_URL`로 실제 DB 연결
