## 배터리 — PyBaMM 성능·수명(열화) 예측
PyBaMM 물리 모델로 리튬이온 셀의 방전·충전 성능을 계산하고, SEI 성장·리튬 도금·활물질 손실을 켠 사이클 시뮬레이션으로 용량 유지율(SOH)·수명(EOL)·열화 원인(LLI/LAM)을 예측합니다. 계산은 이 서버에서만 하고 외부로 보내지 않습니다.

### 쓰는 법
1. 왼쪽 **셀** — 파라미터 세트(셀·화학계·공칭 용량·지원 열화가 태그로 보임), 모델(SPM 빠름 / SPMe 권장 / DFN 정확·느림), 주변 온도, 열 모델(집중=발열 반영)
2. **성능 시뮬레이션**
   - 방전 C-rate 비교: `0.2, 0.5, 1, 2` 처럼 입력 → 전압-용량 곡선, 온도, SOC, 표(용량·에너지·평균 전압·최고 온도)
   - CC-CV 충전: 충전 C-rate·CV 종료 전류 → 80% 도달 시간·전체 충전 시간
   - 전류 프로파일: CSV(시간 s, 전류 — **양수=방전, 음수=충전**, 단위 A 또는 C-rate) 올리기 또는 **예시 프로파일 만들기**(합성 펄스)
3. **수명 예측** — 세트는 **OKane2022**(SEI·도금·LAM 모두 지원) 권장, 모델 SPM
   - 열화 서브모델 체크(세트에 파라미터가 없는 것은 회색), 최대 사이클(50 → 200 → 500 → … 단계로 계산, SOH 기준 도달 시 멈춤)
   - 시나리오 1~4개: 이름·온도·충전 C·방전 C·DoD. **충전 C-rate 비교 / 온도 비교 / DoD 비교** 버튼으로 바로 채우기
   - 아래에 실제 PyBaMM 실험 문자열(예: `Charge at 2C until 4.2V`)이 미리 보입니다. 직접 쓰려면 "실험 단계 직접 입력"
4. **AI 질문** — "45도에서 2C 급속충전하면 수명 얼마나 줄어?"처럼 물으면 로컬 LLM 이 설정을 만들고(기준 시나리오 자동 포함) 계산 후 해설합니다
5. 결과 — 그래프에 마우스를 올리면 값, 그래프마다 **SVG** 저장, 아래 **CSV·PNG·result.json** 다운로드, **AI 해설** 버튼
6. **작업·이력** 탭 — 계산 중·대기·완료 목록. 긴 계산은 창을 닫아도 서버에서 계속 돌고, 나중에 열어 볼 수 있습니다(동시 2개, 나머지 대기)

### 팁
- 결과는 **물리 모델 시뮬레이션**입니다. 고른 세트의 셀과 내 셀이 다르면 정량값은 달라집니다 — 실측으로 보정(파라미터 추정) 전에는 **조건 간 비교(경향)** 로 쓰세요
- EOL 에 **외삽** 표시가 붙으면 계산한 사이클 범위 밖을 a·√n + b·n 식으로 늘린 값입니다. "계산 범위의 N배"가 클수록 불확실 — 최대 사이클을 늘려 다시 돌리면 정확해집니다
- PyBaMM 기본 열화 파라미터는 문헌 예시값이라 열화가 느리게 나옵니다(OKane2022 1000 사이클에 SOH 1~3% 감소). 실측 열화 속도가 있으면 **SEI 속도 배율**로 맞춰 볼 수 있습니다
- SOH 는 저율(평형) 용량 기준입니다. 전체 방전 사이클이면 '사이클 방전 용량 유지율' 그래프도 함께 나옵니다
- 고온이 오히려 수명이 길게 나오면 열화 모드 그래프를 보세요 — 저온·급속충전에서는 리튬 도금, 고온에서는 SEI 가 커지는 서로 다른 메커니즘이 경쟁합니다
- 1000 사이클 × 시나리오 1개 ≈ 1분(SPM). DFN 은 수십 배 느리니 사이클을 줄이세요
- AI 해설에 계산 결과에 없는 숫자가 나오면 ⚠ 로 표시됩니다. 표의 값을 기준으로 보세요
