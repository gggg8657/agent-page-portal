## 파동이 스튜디오 — KAERI 캐릭터 3D·2D 리그
한국원자력연구원 공식 캐릭터 **파동이**를 3D와 2D로 다시 만든 도구입니다. 말로 시키면 움직이고, 표정을 바꾸고, 소리 내어 말합니다.
모양은 원본 턴어라운드 영상(360° 회전 180장)을 역으로 재서 만들었고(머리·몸통 비율, 무늬 위치, 얼굴 배치), 팔꿈치·발목·발이 있습니다.
3D와 2D는 같은 관절·표정 값을 함께 써서 **나란히** 보면 똑같이 움직입니다.

### 쓰는 법
1. 위쪽 **3D / 2D / 밤티 3D / 밤티 2D / 나란히**에서 보기를 고릅니다(밤티 = 예전 v0.1 눈대중 모양 — 같은 명령을 따라 하지만 장면·옷은 없어서 비슷한 옛 동작으로 대신). 3D는 마우스로 돌려 보고(드래그) 휠로 확대합니다. **돌려 보기**를 누르면 원본 턴어라운드처럼 천천히 한 바퀴씩 돕니다
2. 오른쪽 입력칸에 말로 시킵니다 — 예) `점프 두 번 하고 손 흔들면서 반갑다고 해`, `너 사자야?`
   - 로컬 LLM(gemma4)이 문장을 **동작 → 표정 → 대사** 순서로 바꿉니다(약 5~15초). 채팅에 `점프×2 → 손 흔들기 “안녕!”` 처럼 해석 결과가 나옵니다
   - LLM이 꺼져 있으면 낱말 규칙(점프·박수·춤·인사·“…”라고 말해 등)으로 대신 움직입니다
3. **동작** 탭: 버튼 35개(손 흔들기·박수·화이팅·엄지 척·점프·춤·한 바퀴·끄덕·도리도리·꾸벅 인사·걷기·달리기·앉기·쿨쿨·갸웃·부끄부끄·엉엉·만세 축하·하늘 날기·가리키기·왼쪽/오른쪽 보기·깜짝·씩씩·하트·노래·에너지 파동·안아 줘, 배경화면에서 가져온 **야근(열일)·사고침(헉)·운동(아령)·스노클링·서핑·하트 들기·갸우뚱**). 누른 순서대로 이어서 하고, **멈춤**으로 비웁니다
   - 머리·몸통은 팔이 뚫고 들어가지 못하는 고정 범위입니다. 팔 길이는 그대로라서, 높이 드는 동작은 손이 머리 아래 가장자리 앞(턱 높이)에서 움직입니다
4. **표정·말** 탭: 표정 15개(헉!·집중(야근)·땀 뻘뻘 포함, 누르면 고정, 다시 누르면 해제), **말하기**(적은 그대로 말함), 목소리(서버 TTS / 브라우저 음성 / 끔), 음높이, 볼 터치, 소품(고깔모자·마이크·엄지·안경·선글라스·물안경·머리띠·아령·하트·책상·서핑보드)
5. **분해·내보내기** 탭
   - 위쪽 **분해** 버튼: 머리(갈기)·얼굴 텍스처·코·머리 무늬·몸통·흰 배·꼬리·팔·다리를 떼어서 이름표와 함께 보여 줍니다. 부품별로 끄고 켤 수도 있습니다
   - **3D 모델 .glb**: 관절 이름(Hips·Neck·Head·Arm_L/R_Joint·Elbow·Hand·Leg_L/R_Joint·Ankle·Foot)이 붙은 서 있는 자세 모델. Blender·Unity·웹 뷰어에서 바로 엽니다
   - **3D/2D 화면 PNG**, **2D 표정 시트 PNG**(표정 12개 + 말하기 입 모양 4단계, 다른 2D 앱의 스프라이트용)

### 장면 (여러 단계 연출)
**동작** 탭 아래 **장면**: 커튼 뒤로 사라지기(다시 나올 때 짠·다른 자리·빼꼼·"앗 아직이요!" 중 하나) · 낮잠(하품 → 꾸벅 → 앉아서 코골이, 콧물방울, 잠꼬대) · 화캉스(팻말 세우고 살금살금 나갔다가 반대쪽에서 개운하게) · 나갔다 오기(커피 들고) · 미니미 친구들(동그란 친구들이 지나가거나 빼꼼, 같이 춤)
- 채팅으로 "커튼 뒤로 사라져 봐", "낮잠 자" 처럼 시켜도 됩니다

### 옷 (기념일에 알아서 입음)
날짜를 보고 기념일 옷을 **하루 전부터 하루 뒤까지** 입습니다(주말에 걸려도 금·월요일에 보이게). 겹치면 명절·국경일·KAERI 기념일 > 생활 기념일 > 계절 순.
- 22벌: 설·추석·대보름·단오·개천절 한복 · 삼일절·광복절 태극기 · 현충일(차분 모드, 10시 묵념) · 부처님오신날 연등 · 어린이날 · 어버이날·스승의 날 카네이션 · 지구의 날 · 과학의 날·하나로 첫 임계 실험복 · KAERI 창립기념일 정장 · 국군의 날 · 한글날 서예 · 할로윈 호박 · 빼빼로 · 발렌타인·화이트데이 · 수능 응원단(입실·듣기평가 시간엔 소리 없이) · 산타 · 원자력의 날 방호복 · 신정·연말 파티 · 장마 우비 · 휴가철 · 겨울 패딩(동지 팥죽) · 평일 19시 이후 잠옷
- 옷마다 장면 5개와 말투가 있고, 포털 펫은 그날 처음 나타날 때 커튼 뒤에서 갈아입고 공개합니다. ⋯ 메뉴 맨 위에 "오늘: …"
- 스튜디오: **표정·말** 탭 → **옷** 에서 자동/기본/옷을 고를 수 있고, 장면의 👘 표시는 그 옷 전용 장면입니다

### 혼자 하는 일 (펫)
걷기만 하지 않고 깡총·스킵·뒤뚱·문워크·데굴데굴 등으로 돌아다니다 중간에 두리번거립니다. 시간·상황에 맞춰 가끔: 아침 커피+폰, 점심 메뉴 고민(11:20–11:50), 스트레칭, 화분 물주기(며칠마다 자라서 꽃), 실험하다 펑, 원자 저글링, 논문 읽다 꾸벅, 택배, 셀카, 종이비행기(페이지를 가로질러 날아감, 누르면 메모), 볼링(금요일 오후 등), 퇴근 인사(17:50–18:30)
- 자리를 비우면: 김동주 찾기(돋보기로 찾다가 마우스를 움직이면 "찾았다!!"), 논문 꾸벅, 낮잠
- 실제 데이터: 대전 유성에 비가 오면 우산 쓰고 첨벙·눈 오면 눈송이 잡기, GPU 가 뜨거우면 서버 랙에 부채질(실제 온도), 포털에서 1분 넘게 걸린 작업이 끝나면 "'도구' 작업 끝났어요!", 화면을 휙 빠르게 스크롤하면 앞니로 바닥에 매달림

### 버전 비교
화면 위 **현재 버전 ▾** 에서 v0.0(맨 처음 초안)·v0.1·v0.2(팔이 늘어나는 판)·v0.3·v0.4(장면)·v0.5(옷)·v0.6(옷 22벌·일상 행동) 을 새 탭으로 열어 지금과 나란히 비교할 수 있습니다.

### 펫 — 포털·모든 도구 화면 아래를 돌아다니는 파동이
이 도구가 켜져 있으면 포털 첫 화면과 모든 도구 화면 맨 아래에 파동이가 나와서 혼자 걷고, 앉고, 춤추고, 마우스 쪽을 쳐다봅니다. 3분 동안 아무것도 안 하면 졸다가, 돌아오면 깹니다.
- **누르기**: 반응(점프·하트·인사…). 너무 여러 번 찌르면 화냅니다. 누를 때마다 친밀도 ♥ 가 오릅니다
- **끌기**: 원하는 곳으로 옮기기. 위로 들었다 놓으면 바닥으로 떨어집니다
- **더블클릭**: 말 걸기 — 로컬 LLM이 지금 보고 있는 도구·시간·요일·지어 준 이름·친밀도를 알고 대답합니다
- **혼잣말**: 4~9분마다 지금 화면에 맞는 한마디(응원·팁·상식). 하루 처음 나타날 때 인사
- **⋯ 메뉴**(마우스를 올리면 보임, 오른쪽 클릭도 됨): 말 걸기 · 보기(2D · 3D · 밤티 2D · 밤티 3D — 밤티는 장면·옷 없이 걷기·옛 동작만) · 소리 켜기(TTS) · 혼잣말 끄기 · 이름 바꾸기 · 스튜디오 열기 · **펫 끄기**
- 끄면 왼쪽 아래에 작은 파동이 동그라미가 남고, 누르면 다시 나옵니다. 켜고 끈 상태·이름·위치·친밀도·대화는 이 브라우저에 저장되고, 다른 탭에도 바로 반영됩니다
- 펫도 혼자 장면을 합니다(큰 장면 사이 20분 이상): 커튼, 화캉스(오전 10:30–11:30·오후 2:30–4시 중 하루 한 번), 나갔다 오기, 가끔 미니미 친구들. 3분 동안 아무것도 안 하면 낮잠(코골이) — 마우스를 움직이면 깹니다
- 화캉스 중에는 화면에 **잠시 자리 비움** 팻말만 남고 1–3분 뒤 돌아옵니다. 다른 페이지로 옮겨도 이어지고, 팻말을 두 번 누르면 바로 돌아옵니다
- ⋯ 메뉴의 🎭 커튼 · 💤 낮잠 · 🧻 화캉스 · ☕ 나갔다 오기 · 🫧 미니미 로 바로 시켜 볼 수 있습니다
- 펫이 입력칸을 가리면 끌어서 옮기거나 잠깐 꺼 두세요

### 다른 프로그램에서 시키기
화면이 열려 있으면 바깥에서 보낸 명령을 받아 바로 실행합니다(📡 표시). 자세한 주소는 **분해·내보내기** 탭 아래에 있습니다.
```
curl -XPOST <주소>/api/push -H 'Content-Type: application/json' -d '{"text":"춤추고 고맙다고 해"}'
curl -XPOST <주소>/api/push -H 'Content-Type: application/json' -d '{"steps":[{"do":"jump","times":2},{"say":"안녕!","expr":"happy"}]}'
```
브라우저 콘솔: `padong.do('wave',2)`, `padong.say('안녕')`, `padong.expr('wink')`, `padong.command('춤춰')`

### 팁
- 목소리는 **TTS 도구(tts-local)**의 한국어 목소리입니다. 꺼져 있으면 입만 움직이니 포털에서 TTS를 켜 주세요. 처음 한 번은 브라우저 자동재생 제한 때문에 화면을 한 번 눌러야 소리가 납니다
- 입 모양은 실제 음성 크기에 맞춰 움직입니다(립싱크). 음높이를 올리면 더 귀여운 목소리가 됩니다
- 3D가 느린 PC는 **2D**만 켜 두면 가볍습니다

### 주의
- 원본은 허쉬위쉬가 디자인한 KAERI 캐릭터입니다. 이 도구의 모델은 공개된 이미지를 보고 다시 만든 **근사 모델**이며 원본 3D 데이터가 아닙니다. **원본 자료** 버튼에서 출처 이미지와 크레디트를 볼 수 있습니다
- 캐릭터 저작권은 KAERI·허쉬위쉬에 있습니다. 대외 배포·상업적 사용 전에는 홍보 담당 부서와 확인하세요
