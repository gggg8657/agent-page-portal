## Meeting — 회의 녹음 → 회의록
녹음 파일을 올리면 받아쓰기, 화자 분리, 회의록, 구간별 인사이트까지 만듭니다. 전부 서버 안에서 처리됩니다.

### 쓰는 법
1. 녹음(m4a·mp3·wav·mp4) 업로드. 화자 수를 알면 **화자 수** 지정(정확도 ↑)
2. 전사·화자분리가 끝나면 **화자 이름 지정**: 화자별 발췌와 ▶ 클립을 듣고 이름 입력
3. 제목·일시·장소 입력 → **회의록 생성**
4. 탭: **회의록** / **인사이트**(구간별 핵심) / **전사본** / 로그 → md·json·txt·**HWPX** 다운로드

### 알아둘 것
- 1시간 녹음은 GPU 기준 수 분, CPU면 더 걸립니다
- 마이크 하나로 녹음한 회의는 화자 분리가 흔들릴 수 있습니다. 이름 지정 단계에서 바로잡으세요
- 액션아이템의 담당·기한은 발언에서 추정한 것이니 확인 후 사용
