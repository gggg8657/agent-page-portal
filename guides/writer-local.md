## Writer — 패턴 글쓰기
건배사·경조사 문구·축사·공지문처럼 형식이 정해진 글을 입력 몇 칸으로 만듭니다.

> 처음 들어오면 **따라 하기**(약 2분)가 저절로 뜹니다 — 연습 자료로 화면을 직접 눌러 보며 배우고, 연습으로 만든 기록은 끝에서 지울 수 있는 것은 지웁니다. 다시 보려면 머리줄 **? 도움 → 따라 하기**, **? 도움 → 사용법** 창의 **영상으로 보기**로 먼저 볼 수도 있습니다.

### 쓰는 법
1. 카테고리 탭(모임·경조사·행사·공문·개인)에서 **패턴 카드** 선택
2. 자동으로 생긴 입력 칸 채우기(모임 성격, 대상, 길이 등)
3. **생성** → 여러 안이 탭으로 나옵니다
4. **더 짧게 / 더 격식 / 더 캐주얼**로 바로 다듬기, **복사**

### 팁
- Humanize KR이 켜져 있으면 **AI 티 제거** 버튼이 나타납니다
- 패턴은 `patterns/*.md` 파일 하나 추가하면 늘어납니다
- 기록은 사용자별로 따로 저장됩니다(포털 계정 기준). 서버 주인은 예전 기록도 그대로 보입니다
