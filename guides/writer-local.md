## Writer — 패턴 글쓰기
건배사·경조사 문구·축사·공지문처럼 형식이 정해진 글을 입력 몇 칸으로 만듭니다.

### 쓰는 법
1. 카테고리 탭(모임·경조사·행사·공문·개인)에서 **패턴 카드** 선택
2. 자동으로 생긴 입력 칸 채우기(모임 성격, 대상, 길이 등)
3. **생성** → 여러 안이 탭으로 나옵니다
4. **더 짧게 / 더 격식 / 더 캐주얼**로 바로 다듬기, **복사**

### 팁
- Humanize KR이 켜져 있으면 **AI 티 제거** 버튼이 나타납니다
- 패턴은 `patterns/*.md` 파일 하나 추가하면 늘어납니다
