## 주간보고 — 개인 작성 · 실(소본부) 취합 (공식 양식 「주간업무보고(서면보고용)」)
이번 주 메모를 대충 적으면 주간보고 항목으로 정리하고, 실에서는 부서별 제출을 한 장짜리 표로 합쳐 HWPX·DOCX 로 내려줍니다. 로컬 LLM 만 쓰고 외부로 보내지 않습니다.

### 개인 주간보고
1. **이름·소본부·부서(실/팀)** 를 적고 주차를 고릅니다(◀ ▶, 월~금 기간 표시). 이 브라우저에 기억됩니다
2. **이번 주 메모** 를 불릿으로 대충 — **과제명**을 `[기본사업]` 처럼 머리에 적으면 그 아래 줄들이 그 과제로 묶이고, 날짜(10/5~10/8, ~10/16)는 기간으로 들어갑니다. — 다음 주 할 일도 같이 적으세요("다음 주:", "예정"). 세부 내용은 줄 앞을 들여 쓰면 **하위 항목**이 됩니다
   - `★` 또는 `핵심` → **주황**, `과기정통부 보고` → **파랑**, `비공개`·`BBS 제외` → **취소선**
   - 외부활동은 `(@장소, 참석자)` 를 적어 두면 그대로 들어갑니다
   - "주간보고에 보통 들어가는 내용"을 펼치면 과제 진도·회의·출장·논문/특허·시험·규제 대응·행사·수상·인력/예산/안전 예시가 있고, 누르면 메모에 줄이 생깁니다
   - 회의록(meeting)·메일 도구를 쓰면 **이번 주 기록에서 가져오기** 로 골라 넣을 수 있습니다
3. **항목으로 정리 (LLM)** → 항목이 **수행업무 / 향후 2주 계획** 으로 나뉘고 과제명·기간이 칸으로 들어갑니다. 출력은 `∙ (과제명)`(굵게) 아래 `- (기간) 내용`
   - 과제명이 없거나 메모에 없던 추정이면 **❓ 과제명** 카드가 뜹니다 — 이 실에서 쓴 과제명에서 고르거나 적고 **적용**. 정하기 전에는 제출할 수 없습니다
   - '성격'(중점목표·성과·행사·기타)은 보고서에 나오지 않는 내부 우선순위입니다 — 1쪽으로 줄일 때 기타부터 뺍니다
4. 지난주에 제출했다면 **지난 '향후 2주 계획' 대조** 가 뜹니다(완료/진행/미착수/미확인). 완료 아닌 것은 **이월** 로 이번 계획에 넣으세요
5. 항목을 고칩니다 — 글 수정, 끌어서 순서 변경(하위 항목까지 같이), **← → 로 들여쓰기 단계**(○ → - → ·), **+ 하위** 로 세부 항목 추가, 체크박스로 핵심(주황)·과기정통부(파랑)·BBS 비게시(취소선), 장소·참석자 칸
6. **❓ 확인이 필요한 약어** 카드에 답합니다 — 약어집에 없거나 뜻이 여럿인 약어는 프로그램이 지어내지 않고 묻습니다.
   후보(약어집의 다른 뜻·공개 약어집, `[제안·확인 필요]` 는 LLM 이 낸 후보)를 고르거나 영문 전체 이름·한글 명칭·한 줄 설명·분야를 직접 적고 **답변 저장**.
   풀이가 필요 없는 표기(장비 고유 이름 등)는 **약어 아님**. 답은 실 약어집에 저장돼 다음부터 모두 자동으로 쓰입니다
7. **규칙 점검** 의 ⚠ 를 해결합니다 — 외부활동 장소·참석자 누락, 날짜 표기 통일, 너무 긴 항목, 수준 3 인데 설명 없는 약어
8. 미리보기를 확인하고 **제출 (저장)** — 실 취합에 반영됩니다. 같은 주차에 다시 제출하면 덮어씁니다. HWPX·DOCX 로 내려받을 수도 있습니다
   - 답하지 않은 약어가 남아 있으면 **제출이 막힙니다**. 꼭 필요하면 '사유를 적고 그래도 제출' (사유가 기록됨)

### 양식 만들기 (과제 등록부)
1. **양식 만들기** 탭에서 소본부·실을 적고 과제를 등록합니다 — 보고서에 쓰는 과제명, 정식 이름(선택), 기본 기간(선택), 담당(실 전체 또는 한 사람). 끌어서 순서, ✕ 로 지우기(아래 '지운 과제'에서 되살림)
   - **지난 제출에서 가져오기**: 최근 4주 동안 실원들이 쓴 과제명을 한 번에 등록
   - 구성원(쉼표)을 적어 두면 사람별 양식을 만들 수 있습니다. 누가 언제 고쳤는지 남습니다
2. **작성 양식 만들기**: 이 실 / 소본부 전체, 사람별, 주차, 형식(엑셀·한글·워드·PPT) → **미리보기** → 내려받기. 과제마다 '∙ (과제명)' 과 빈 '- (기간) 내용' 줄이 미리 들어 있어 내용만 채우면 됩니다
3. 등록한 과제는 과제명 질의 카드의 후보가 되고, 보고서의 과제 순서도 등록 순서를 따릅니다. 올린 파일의 과제명이 등록 이름과 비슷하면 점검표에 '→ 등록 이름' 칸이 뜹니다(체크할 때만 바꿈)
4. 과제마다 **별칭**(쉼표)을 적어 두면 그 이름으로 쓴 항목은 자동으로 등록 이름으로 바뀝니다(정리·가져오기·취합 모두, 바꾼 기록이 남음). 등록 과제가 있으면 LLM 은 그 목록에서만 과제명을 고릅니다

### 과제 합치기 · 이름 바꾸기
- 개인·취합 화면 위의 **과제 막대**에서 과제 칩의 ✎ 로 이름을 바꿉니다
- 같은 과제가 두 이름으로 나뉘었으면 둘 이상 체크 → **선택 과제 합치기** → 남길 이름 고르기(또는 새 이름). **앞으로도 이 이름은 합치기** 를 체크하면 별칭으로 저장돼 다음부터 자동
- 비슷한 이름은 **같은 과제로 묶을까요? (A → B)** 카드로 제안합니다 — **묶기** 또는 **따로 두기**(다시 묻지 않음). 저절로 합치지는 않습니다

### 파일로 넣기 · 엑셀
- **작성 양식 받기**: 엑셀 · 한글(HWPX) · 워드 · PPT 중 편한 것 — 공식 양식 모양에 '∙ (과제명)' / '- (기간) 내용' 자리가 있습니다. 채워서 **파일 올리기**
  - 엑셀: '작성' 시트에 한 줄에 한 항목(과제명·구분·시작일·종료일·내용·단계·핵심/과기정통부/비게시 O·장소·참석자)
  - 한글·워드: 실 칸 옆 내용 칸에 '∙ (과제명)' 아래 '- (기간) 내용'. 핵심은 주황 글자, 과기정통부는 파랑 글자, 비게시는 취소선
  - PPT: 실마다 한 장. 목록 수준 1단계 = 과제명, 2단계 = (기간) 내용, 3단계 = 하위. 색·취소선은 글자 서식으로
- HWPX·DOCX·엑셀·HWP·PDF·TXT 도 올릴 수 있습니다(여러 개, 형식 섞어도 됨). 이 도구로 내보낸 파일은 그대로 돌아오고, 공식 양식대로 쓴 문서는 표·글머리·글자색·취소선으로 읽습니다. LLM 은 쓰지 않습니다
- 올리면 **행별 점검표**(⛔ 오류 / ⚠ 과제명·기간 없음 / 모르는 약어)가 나옵니다 → '지금 항목에 더하기' 또는 '바꾸기' → **반영**. 문서 안 '약어: 풀이' 줄은 체크해 약어집에 저장
- 내려받기의 **엑셀(보고서형)** 은 공식 양식 모양, **엑셀(데이터형)** 은 입력 양식 모양이라 엑셀에서 고쳐 다시 올릴 수 있습니다. **PPT** 는 실마다 한 장

### 실(소본부) 취합
1. **설정·양식** 탭에서 한 번만 `소본부: 부서1, 부서2, …` 를 등록합니다(미제출 부서 표시용)
2. **실 취합** 탭 → 소본부·주차 → 부서별 제출 현황(미제출은 빨강) → **취합 (LLM)** — 또는 실원들이 보낸 엑셀·HWPX·DOCX 를 **파일 올리기**로 한꺼번에 넣기(LLM 없이 실별 행으로)
3. 부서별로 같은 일은 합치고 간결하게 정리된 표가 나옵니다. LLM 이 빠뜨린 항목은 원문 그대로 되살아나고(⚠ 표시), 핵심·과기정통부·비게시 표시는 원래 항목에서 그대로 가져옵니다
4. **분량 막대** 가 1쪽을 넘으면 **압축 (LLM)** — 덜 중요한 항목부터 줄이되 핵심·과기정통부 항목은 남깁니다. 뺀 항목은 '되살리기' 가능
5. **❓ 약어 질의 목록** — 취합자가 모르는 약어는 부서·작성자가 함께 나옵니다. 답을 알면 바로 입력, 모르면 **질의 문구 복사**(메신저·메일에 붙여 넣기) 또는 **메일로 묻기 ↗**, **질의 메모**(언제 누구에게 물었는지)를 남깁니다
6. 고친 뒤 **저장**, 그리고 **HWPX / DOCX** 내려받기. BBS 게시용은 **BBS 게시용 HWPX·DOCX·텍스트** (취소선 항목과 범례 제외). 미확인 약어가 남아 있으면 내보내기 전에 확인 창이 뜨고, 문서에 `[약어 확인 필요]` 가 표시된 채 나갑니다

### 표기 규칙
- 공식 양식 그대로: 제목 → `Ⅰ. 소본부` → 표 **1. 수행업무**(이번 주 월~금) → 표 **2. 향후 2주 계획**(다음 주 월~그다음 주 금) → **3. 특기 및 애로사항**
- 각 표는 실(부서)마다 한 행, 칸 안은 `∙ (과제명)` 굵게 → `- (2.24~3.5) 내용`, 마감은 `(~3.6)`, 하루는 `(3.20)`. 하위 항목은 한 단계 안으로(·), 둘째 줄은 글머리 뒤에 맞춥니다
- 양식 아래 ※ 작성 지침(색·1p·중점목표 등·약어·외부활동)은 보고서에 넣지 않고 도구가 지킵니다
- 칸 안 순서: (a) 중점목표 연계 → (b) 주요 연구(경영) 성과·대외활동 → (c) 주요 행사(연구원 주관)·수상 → 기타
- 핵심사항 **주황**, 과기정통부 보고사항 **파랑**(둘 다면 파랑 굵게), BBS 비게시 **취소선**
- 모든 약어는 문서 끝 **※ 약어** 아래에 **한 줄에 하나씩, 약어는 굵게** 풀어 씁니다(미리보기 옆에서 항목 아래 줄·괄호 병기로 바꿀 수 있음). **풀이 수준**을 분야별로 고릅니다
  - 1 전체명만: **SMR**: Small Modular Reactor · 2 전체명 + 한글: **KINS**: Korea Institute of Nuclear Safety(한국원자력안전기술원)
  - 3 + 쉬운 설명: **RAG**: Retrieval-Augmented Generation(검색증강생성) — 문서를 찾아 근거로 답하는 AI 방식 — 약어와 설명이 한 목록에 같이 들어갑니다
  - `이상탐지(VAD)`·`오탐(FP)` 처럼 한글 뜻만 붙인 약어도 ※ 약어에 올라갑니다(영문 전체 이름을 이미 쓴 경우만 뺌)
  - 기본(원자력 전문가 독자): 원자력 1 · 기관·정책 2 · AI 3 · 컴퓨터 2 · 일반 2. **독자 프리셋** 버튼: 원자력 전문가 / 과기정통부·경영진 / 일반 공개
- 외부활동은 `내용 (@장소, 참석자)` — 외부활동에만 붙입니다. 연구원 안에서 동료와 한 일·전화·메일엔 안 붙이고, 문장에 이미 있는 이름은 괄호에 다시 쓰지 않습니다. 설정 **참석자 표기**: 외부활동만(기본) / 항상 / 안 함

### 팁
- 메모에 없는 숫자·영문 표기가 생기면 ⚠, 메모에 없는 장소·참석자는 자동으로 지웁니다. ⚠ 가 붙은 항목은 꼭 확인하세요
- **약어집** 탭: 사내(답변·수정) > 시드(국내 기관·원자력 31, AI·컴퓨터 66) > 공개(NUREG-0544 7,929 · NIST CSRC 3,911 — 후보로만). 분야로 거를 수 있고, 누가·언제 고쳤는지 남습니다. DT·ROM·PIE·RL 처럼 뜻이 여럿인 약어는 문장 맥락으로 정하고, 못 정하면 묻습니다
- **3. 특기 및 애로사항**은 메모의 '특기·애로' 줄이 자동으로 들어가고, 항목 목록 아래 칸에서 고칠 수 있습니다(취합은 실 이름을 붙여 모음)
- 같은 서버에 접속하는 사람은 모든 제출본을 볼 수 있습니다. 대외비는 '비공개' 표시하고 필요한 만큼만 적으세요
