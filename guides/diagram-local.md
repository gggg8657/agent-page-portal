## Diagram — 말로 그리는 다이어그램
설명을 쓰면 Mermaid 다이어그램이 바로 그려지고, 대화로 다듬습니다.

> 처음 들어오면 **따라 하기**(약 2분)가 저절로 뜹니다 — 연습 자료로 화면을 직접 눌러 보며 배우고, 연습으로 만든 기록은 끝에서 지울 수 있는 것은 지웁니다. 다시 보려면 머리줄 **따라 하기**, **?** 창의 **영상으로 보기**로 먼저 볼 수도 있습니다.

### 쓰는 법
1. 유형(자동·flowchart·sequence·class·ER·state·gantt·mindmap…) 선택 또는 자동
2. 왼쪽 채팅에 설명 — 예: "사용자가 로그인하면 인증서버가 토큰을 발급하고…"
3. 오른쪽에 그림이 뜨면 **다듬기**로 이어서 지시("DB를 원통으로", "라벨 영어로")
4. **SVG / PNG 다운로드**, **Mermaid 소스 복사**. 소스를 직접 고쳐도 즉시 반영

### 팁
- 예시 6개(조직도·승인 절차·실험 파이프라인…)를 눌러 감을 잡으세요
- 그림이 안 그려지면 자동으로 한 번 수정 시도 → 그래도 안 되면 소스 칸에서 직접 수정
- 기록은 사용자별로 따로 저장됩니다(포털 계정 기준). 서버 주인은 예전 기록 포함
