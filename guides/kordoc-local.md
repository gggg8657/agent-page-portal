## kordoc — 공문서 읽기·초안·윤문
HWP·HWPX·PDF·DOCX·XLSX(스캔본·이미지 포함)를 읽고, 요약·질문·공문서 초안을 HWPX로 만듭니다.

> 처음 들어오면 **따라 하기**가 저절로 뜹니다(다시 보려면 머리줄 **? 도움 → 따라 하기** — 약 3분 — 가상 보고서 요약): 연습 자료로 화면을 직접 눌러 보며 배우고, 연습으로 만든 기록은 끝에서 지울 수 있습니다. **? 도움 → 사용법** 창의 **영상으로 보기**로 먼저 볼 수도 있습니다.

### 쓰는 법
1. 파일 선택(없이도 요청만으로 초안 가능)
2. **작업** 선택 — **요약**(요청 비워도 됨) / **질문**(문서 근거로 답변, 없으면 "문서에 없음") / **공문서 초안 → HWPX**(프리셋 선택 후 요청 작성)
3. **실행** → 결과 아래 **⬇ HWPX 내려받기** (한컴에서 바로 열림)
4. 결과 화면의 **윤문하기**로 방금 만든 문서의 문장만 다듬어 서식 그대로 다시 받기

### 팁
- 초안은 `kordoc lint`로 표기법(날짜·금액·붙임) 검수가 자동으로 붙습니다. 표기법 탭 확인
- 기안문은 표준 서식(별지 제1·2호)에 값을 채우는 방식이라 수신·제목·본문만 쓰면 됩니다
- 긴 문서는 앞 12,000자만 모델에 들어갑니다
- 기록은 사용자별로 따로 저장됩니다(포털 계정 기준). 서버 주인은 예전 기록도 그대로 보입니다. 등록한 양식은 모두가 함께 씁니다(공유됨)
