## CAD Agent — 로컬 CAD 초안·검증
말로 설명하거나 그림·DXF를 올리면, 로컬 LLM이 설계 의도(IR)를 쓰고 CAD 엔진이 도면·3D를 만든 뒤 규칙으로 검증합니다. 전부 서버 안에서 처리됩니다.

### 할 수 있는 것 (위쪽 **작업**에서 고르거나 자동 분류)
- **원자로·원자력 설비**: 일체형/루프형 PWR, 풀형 SFR, 고온가스로, 개방수조 연구로, MSR, 핫셀, 사용후핵연료 저장조 → 사이징·3D(절개)·GA 단면도·계통도
- **3D 부품**: "L형 모터 브래킷, NEMA17 M3 4개…" → STEP·STL·3면도
- **2D 판재**: "200x100 판재 R10, M6 4개, t3" → 가공도 DXF·레이저용 DXF
- **ICT 배치도·개황도**: "B2 승강장 CCTV 12, AP 4, 통신실 B1" → 배치도·계통도·랙도·일람표·3D 목업
- **기존 DXF 수정·분석**: DXF 첨부 + "승강장에 AP 4개 추가" → `원본_rev_A.dxf` (원본은 그대로)

### 쓰는 법
1. 왼쪽 **예시 버튼**을 눌러 보세요
2. 요청 입력 → 필요하면 📎로 **DXF 또는 그림(PNG·JPG)** 첨부 → **실행** (Ctrl+Enter)
   - 그림은 **선택**입니다. 첨부하면 그림을 판독(치수·개수·배치)해 참고하고, **명령이 우선**합니다. "이거 CAD로"처럼 작업을 안 밝히면 그림을 보고 작업을 고릅니다
3. 오른쪽 탭: **도면**(휠 확대·드래그 이동) · **3D**(드래그 회전) · **IR** · **검증 보고서** · **파일**(다운로드) · **📚 지식 DB**
4. 결과를 보고 같은 칸에 "증기발생기 12기로", "벽두께 2.5로"처럼 쓰면 **새 리비전(R01…)** 이 생기고 바뀐 점이 기록됩니다
5. **IR 탭**에서 값을 직접 고치고 **IR로 재빌드**를 누르면 LLM 없이 바로 다시 만듭니다

### 📚 지식 DB — 설계 원칙을 직접 고치기
- 노형·시설마다 **설계 원칙**(한 줄에 하나), **설계 기본값**, **검증 규칙**이 있습니다. 에이전트는 원칙을 반드시 따르고, 검증 규칙을 어기면 스스로 고칩니다
- 고친 뒤 **수정자·사유**를 적고 **저장** → 다음 요청부터 바로 반영. **원본으로**를 누르면 되돌립니다 (이력과 백업이 남음)
- **복제해 새 원형**으로 사내 설계안(예: "SFR 사내안")을 따로 만들 수 있습니다
- 검증 규칙 예: `{"id":"SFR-K1","expr":"n_pump == n_ihx","msg":"펌프 수 = IHX 수","severity":"error"}` 또는 `{"rel":"above","a":"steam_generator","b":"core"}`

### 결과 읽는 법
- 상태: **통과** / **경고**(검토 권장) / **규칙 위반**(error) / **실패**. 규칙 위반은 LLM이 최대 3번 스스로 고칩니다
- 보고서의 **엔진 가정**과 **적용된 설계 원칙**을 꼭 확인하세요

### 알아둘 것
- 모든 결과는 **초안(DRAFT — NOT FOR CONSTRUCTION)** 입니다. 엔지니어 검토 전 제작·시공 금지
- 지식 DB 수치는 공개 교과서 수준의 **대표값**입니다. 사내 기준으로 바꿔 쓰세요
- 그림 판독(VLM)은 틀릴 수 있습니다(개수·방향). 보고서의 "이미지 판독"을 확인하세요
- DWG는 DXF로 변환해서 올리세요
