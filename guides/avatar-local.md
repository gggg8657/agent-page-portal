## Avatar — 가상 캐릭터 스튜디오 · 내 얼굴 아바타 (토이)
두 가지 탭이 있습니다. **✨ 가상 캐릭터 만들기**: 말로 묘사한 가상 인물을 그리고, 말하게·움직이게 합니다. **🙂 내 얼굴 아바타**: 본인 사진·목소리로 말하는 영상.

### 가상 캐릭터 만들기
1. 캐릭터를 말로 묘사(나이·성별·머리·옷·분위기) → **스타일**(실사·버추얼 휴먼·3D 애니·애니메·웹툰·일러스트)·**구도**(얼굴·상반신·전신)·장수 → **그리기** (장당 약 25초, 처음 한 번은 모델 준비 1~2분)
2. 마음에 드는 그림을 클릭
3. **말하게 하기**: 대사 → 립싱크(상반신·전신은 몸은 두고 얼굴만). 목소리 샘플을 넣으면 그 목소리로
4. **움직이게 하기**: "손 흔들며 웃는다" 같은 동작 → 몸 전체가 움직이는 영상(빠르게 약 3초, 1~2분). 대사를 쓰면 음성을 입힘(입모양은 안 맞음)
5. **Persona 캐릭터로**: 이름·성격을 쓰면 Persona 에 그 얼굴로 새 캐릭터가 생깁니다
- 갤러리엔 말하기·움직이기까지 끝낸 영상만 올라갑니다. 실존 인물·유명인을 닮게 묘사하지 마세요. 노출·선정적인 그림은 그리지 않습니다

### 내 얼굴 아바타 쓰는 법
본인 사진과 목소리 샘플로, 내가 말하는 짧은 립싱크 영상을 만듭니다. Persona 의 "고화질 클립"도 이 도구가 만듭니다.

1. **동의 체크** — 내 얼굴·목소리(또는 명시적으로 동의한 사람)만. 타인 얼굴 교체(face swap)는 없습니다
2. 정면 얼굴 사진 업로드 (얼굴이 크게, 안경·측면 X)
3. 목소리 샘플 10초: 파일 업로드 또는 **● 녹음**. 샘플에서 말한 문장을 적어 주면 복제가 정확해집니다
4. 대사 입력 → **생성** → 진행 로그 → 재생·다운로드. 지난 결과는 갤러리

### 갤러리에서 지우기
- 하나만: 항목에 마우스를 올리면(휴대폰은 항상) 오른쪽 위에 **🗑** → 확인
- 여러 개: 갤러리 오른쪽 **선택** → 지울 항목을 눌러 고르기(✓) → **선택 삭제 (N)** → 확인. **전체 선택 / 선택 해제**, 끝나면 **완료**
- 영상·음성·사진·후보 그림이 함께 지워집니다. 바로 아래 **되살리기**를 누르면 방금 지운 것들이 돌아옵니다
- 지운 파일은 실제로는 데이터 폴더의 `.trash/<지운 시각>/` 으로 옮겨 둡니다. 나중에 되살리려면 그 안의 폴더를 데이터 폴더로 다시 옮기고, 완전히 비우려면 `.trash` 폴더를 지우세요
- Persona 로 보낸 캐릭터는 Persona 쪽에 따로 복사돼 있어 갤러리에서 지워도 그대로 남습니다

### 예시
- 내 사진 + 내 목소리 10초 + "올해도 다들 고생 많으셨습니다" → 송년 인사 영상

### 알아둘 것
- 샘플이 없으면 TTS 도구의 목소리(한국어 뉴스 톤)로 말합니다 — 내 목소리 아님
- 목소리 복제는 한국어로 학습된 F5-TTS(team-lucid/F5-TTS-ko)를 씁니다. 샘플은 잡음 없이 10초 안팎, 말한 문장을 정확히 적을수록 닮습니다
- GPU 에서 한 문장 30초 안팎(목소리 복제 포함), 샘플 없이 TTS 목소리면 10초 안팎
- "얼굴을 찾지 못했습니다"가 뜨면 더 정면·더 크게 나온 사진으로

### 주의
- 동의 없이 타인 얼굴·목소리로 영상을 만드는 것은 딥페이크 처벌법·초상권 위반입니다
- 결과물을 밖으로 배포하지 마세요. 사진·결과는 이 서버 데이터 폴더에만 남습니다
