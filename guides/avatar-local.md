## Avatar — 내 얼굴·내 목소리 아바타 (토이)
본인 사진과 목소리 샘플로, 내가 말하는 짧은 립싱크 영상을 만듭니다. Persona 의 "고화질 클립"도 이 도구가 만듭니다.

### 쓰는 법
1. **동의 체크** — 내 얼굴·목소리(또는 명시적으로 동의한 사람)만. 타인 얼굴 교체(face swap)는 없습니다
2. 정면 얼굴 사진 업로드 (얼굴이 크게, 안경·측면 X)
3. 목소리 샘플 10초: 파일 업로드 또는 **● 녹음**. 샘플에서 말한 문장을 적어 주면 복제가 정확해집니다
4. 대사 입력 → **생성** → 진행 로그 → 재생·다운로드. 지난 결과는 갤러리

### 예시
- 내 사진 + 내 목소리 10초 + "올해도 다들 고생 많으셨습니다" → 송년 인사 영상

### 알아둘 것
- 샘플이 없으면 TTS 도구의 목소리(한국어 뉴스 톤)로 말합니다 — 내 목소리 아님
- 목소리 복제는 한국어로 학습된 F5-TTS(team-lucid/F5-TTS-ko)를 씁니다. 샘플은 잡음 없이 10초 안팎, 말한 문장을 정확히 적을수록 닮습니다
- GPU 에서 한 문장 30초 안팎(목소리 복제 포함), 샘플 없이 TTS 목소리면 10초 안팎
- "얼굴을 찾지 못했습니다"가 뜨면 더 정면·더 크게 나온 사진으로

### 주의
- 동의 없이 타인 얼굴·목소리로 영상을 만드는 것은 딥페이크 처벌법·초상권 위반입니다
- 결과물을 밖으로 배포하지 마세요. 사진·결과는 이 서버 데이터 폴더에만 남습니다
