## Avatar — 가상 캐릭터 스튜디오 · 내 얼굴 아바타 (토이)
두 가지 탭이 있습니다. **✨ 가상 캐릭터 만들기**: 말로 묘사한 가상 인물을 그리고, 말하게·움직이게 합니다. **🙂 내 얼굴 아바타**: 본인 사진으로 말하는 영상.
목소리는 모두 TTS 도구(tts-local)의 한국어 목소리입니다 — 목소리 복제 기능은 없습니다. TTS 도구가 꺼져 있으면 "TTS 도구(tts-local)를 켜 주세요" 가 뜨니 포털에서 켜 주세요.

### 가상 캐릭터 만들기
1. 캐릭터를 말로 묘사(나이·성별·머리·옷·분위기) → **스타일**(실사·버추얼 휴먼·3D 애니·애니메·웹툰·일러스트)·**구도**(얼굴·상반신·전신)·장수 → **그리기** (Qwen-Image-2512, 장당 약 40초, 처음 한 번은 모델 준비 약 20초)
2. 마음에 드는 그림을 클릭
3. **말하게 하기**: 대사 → 품질을 고르고 실행
   - **최고 품질**(기본, Wan2.2-S2V): 음성에 맞춰 입·표정·고개·손까지 상반신이 자연스럽게 움직입니다. **대사 5초마다 약 25분** — 5초를 조금만 넘어도 두 배가 되니 짧게 쓰세요
   - **빠르게**(SadTalker): 몸은 그대로 얼굴만 움직임, 수십 초. 그림체(애니·웹툰)는 얼굴 인식이 안 될 수 있음
4. **움직이게 하기**: "손 흔들며 웃는다" 같은 동작 → 몸 전체가 움직이는 5초 영상(Wan2.2 I2V-A14B). **최고 품질** 720p 약 30~35분 / **빠르게** 480p 약 7분. 대사를 쓰면 음성을 입힘(입모양은 안 맞음 — 입모양까지 맞추려면 '말하게 하기')
   - 진행 칸에 "영상 12/40 단계 · 340초 지남" 처럼 단계와 걸린 시간이 나옵니다. 창을 닫으면 결과를 못 받으니 끝날 때까지 열어 두세요
5. **Persona 캐릭터로**: 이름·성격을 쓰면 Persona 에 그 얼굴로 새 캐릭터가 생깁니다
- 갤러리엔 말하기·움직이기까지 끝낸 영상만 올라갑니다(한 캐릭터에 둘 다 만들면 둘 다 보임). 실존 인물·유명인을 닮게 묘사하지 마세요. 노출·선정적인 그림은 그리지 않습니다

### 내 얼굴 아바타 쓰는 법
본인 사진과 대사로, 내 얼굴이 말하는 짧은 립싱크 영상을 만듭니다(목소리는 TTS 도구). Persona 의 "고화질 클립"도 이 도구가 만듭니다.

1. **동의 체크** — 내 얼굴(또는 명시적으로 동의한 사람)만. 타인 얼굴 교체(face swap)는 없습니다
2. 정면 얼굴 사진 업로드 (얼굴이 크게, 안경·측면 X)
3. 대사 입력 → **생성** → 진행 로그 → 재생·다운로드. 지난 결과는 갤러리

### 갤러리에서 지우기
- 하나만: 항목에 마우스를 올리면(휴대폰은 항상) 오른쪽 위에 **🗑** → 확인
- 여러 개: 갤러리 오른쪽 **선택** → 지울 항목을 눌러 고르기(✓) → **선택 삭제 (N)** → 확인. **전체 선택 / 선택 해제**, 끝나면 **완료**
- 영상·음성·사진·후보 그림이 함께 지워집니다. 바로 아래 **되살리기**를 누르면 방금 지운 것들이 돌아옵니다
- 지운 파일은 실제로는 데이터 폴더의 `.trash/<지운 시각>/` 으로 옮겨 둡니다. 나중에 되살리려면 그 안의 폴더를 데이터 폴더로 다시 옮기고, 완전히 비우려면 `.trash` 폴더를 지우세요
- Persona 로 보낸 캐릭터는 Persona 쪽에 따로 복사돼 있어 갤러리에서 지워도 그대로 남습니다

### 예시
- 내 사진 + "올해도 다들 고생 많으셨습니다" → 송년 인사 영상

### 알아둘 것
- 목소리는 TTS 도구의 한국어 목소리(뉴스 톤) 하나입니다 — 내 목소리 아님
- GPU 에서 한 문장 30초 안팎
- "얼굴을 찾지 못했습니다"가 뜨면 더 정면·더 크게 나온 사진으로

### 주의
- 동의 없이 타인 얼굴로 영상을 만드는 것은 딥페이크 처벌법·초상권 위반입니다
- 결과물을 밖으로 배포하지 마세요. 사진·결과는 이 서버 데이터 폴더에만 남습니다
