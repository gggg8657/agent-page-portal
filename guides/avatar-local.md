## Avatar — 내 얼굴·내 목소리 아바타 (토이)
본인 사진과 목소리 샘플로, 내가 말하는 짧은 영상을 만듭니다. 개인 실험용이며 포털 목록에서는 숨겨져 있습니다.

### 쓰는 법
1. **동의 체크** — 내 얼굴·목소리(또는 동의한 사람)만. 타인 얼굴 교체는 할 수 없습니다
2. 정면 얼굴 사진 업로드
3. 목소리 샘플 10초: 파일 업로드 또는 **● 녹음**. 샘플에서 말한 문장을 적어 주면 복제가 정확해집니다
4. 대사 입력 → **생성** → 진행 로그 → 재생·다운로드. 지난 결과는 갤러리

### 알아둘 것
- 샘플이 없으면 TTS 서버 목소리로 말합니다(내 목소리 아님)
- 기본 복제 모델은 영어·중국어 학습이라 한국어는 어색할 수 있음
- CPU 는 10초 영상에 수 분, GPU 는 수십 초
